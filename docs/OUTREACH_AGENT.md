# Outreach Agent

## Purpose

The Outreach Agent is a separate value lane inside Instaply.

It is for users who want:

- relevant people discovery
- company/person research
- personalized outreach drafting
- optional sending and follow-up structure

## Workflow

1. user chooses a job
2. Instaply finds likely relevant contacts
3. Instaply researches available public context
4. Instaply drafts a personalized outreach note
5. user reviews or allows sending based on plan/settings
6. Instaply logs contact history and applies cooldown rules

## Guardrails

- no duplicate outreach to the same contact within cooldown window
- no unsafe claims about personal relationships
- no fabricated background details
- use public/company-role context when detailed person data is weak

## Data Needed

- company
- role
- user profile
- resume
- company context
- people lookup results
- outreach history

## Monetization

Outreach Agent should be:

- separate paid module
or
- included in Agent Suite

This makes pricing easier and keeps the value proposition clear.
