# Pricing

## Launch Recommendation

Do not launch with unlimited auto-apply.

Launch with:

- free starter credits
- a clear paid upgrade path
- supported auto-apply only on higher tiers

## Suggested Plans

### Free Trial

- 3 free applications or apply-ready runs
- 5 packet generations
- 7 day access window

Purpose:

- prove it works
- reduce skepticism
- create conversion events

### Starter

- `$29/month`
- search and ranking
- tailored resume and cover letter packets
- one-job-per-email alerts

### Pro

- `$99/month`
- more searches
- more packet generation
- stronger discovery features
- company recommendations
- portal selection

### Agentic Apply

- `$249/month`
- supported portal auto-apply
- evidence-based application reporting
- blocked-question review
- priority support

### Team / Coach / School

- custom annual pricing
- tester seats
- admin dashboard
- usage reporting
