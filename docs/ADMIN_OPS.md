# Admin and Operations

## Admin Needs

Instaply should have an internal admin surface for:

- user plan overrides
- tester flags
- credits adjustment
- support diagnostics
- audit and incident review

## Tester Controls

Tester accounts should support:

- free credits
- access to beta automation
- stricter logging
- rapid feature flag changes

## Enterprise Controls

- tenant isolation
- per-user audit logs
- queue visibility
- worker failure diagnostics
- rate limit overrides
- role-based access control

## Internal Event Types

- search_run_started
- search_run_completed
- packet_generated
- application_planned
- application_attempted
- application_submitted
- application_blocked
- application_question_flagged
- application_answer_saved
- outreach_generated
- outreach_sent
- billing_plan_changed
- tester_flag_changed
