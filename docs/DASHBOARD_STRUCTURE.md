# Dashboard Structure

## Main Navigation

- Overview
- Search
- Applications
- Outreach
- Documents
- Billing
- Settings

## Overview

Shows:

- jobs found today
- strong-fit jobs
- packet generation usage
- application credits remaining
- outreach credits remaining
- recent agent activity

## Search

Shows:

- target roles
- portal selection
- suggested companies
- user-added companies
- company allowlist and denylist
- recent search runs
- recommended jobs

## Applications

Shows:

- apply queue
- supported portal status
- blocked questions
- unanswered-question review queue
- applied / skipped / blocked outcomes
- evidence and screenshots

## Outreach

Shows:

- people discovered
- outreach drafts
- sent history
- cooldown state
- follow-up opportunities

## Documents

Shows:

- generated resumes
- generated cover letters
- packet versions
- favorites / pinned templates

## Billing

Shows:

- current plan
- credits remaining
- credit packs
- invoices
- PayPal / Stripe payment state

## Settings

Shows:

- account info
- Google / email auth settings
- profile and application info
- resume format preferences
- cover-letter preferences
- portal preferences
- company preferences
- auto-submit preference
- tester flags if enabled

## Onboarding Flow

Should collect:

- identity
- authorization and sponsorship details
- job search preferences
- resume preferences
- cover-letter preferences
- application answer vault
- automation policy

## Control Model

The dashboard should also expose:

- current run mode
- stage-by-stage results
- utility actions like dry run, retry, mark blocked, and mark applied
- max applications per run
- blocked-question review actions
